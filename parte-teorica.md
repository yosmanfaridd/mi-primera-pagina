# Parte Teórica – Introducción a Aplicaciones Web

## 1. ¿Qué es HTML y cuál es su función en la web?

HTML significa **HyperText Markup Language** o Lenguaje de Marcado de Hipertexto. Es el lenguaje que se utiliza para crear la estructura y el contenido de una página web. Por medio de HTML podemos agregar títulos, párrafos, imágenes, enlaces, botones y otros elementos.


## 2. ¿Qué es una etiqueta HTML y menciona las etiquetas más comunes?

Una etiqueta HTML es una instrucción que permite definir los diferentes elementos de una página web.

Algunas etiquetas comunes son:

- `<html>`: representa el documento HTML.
- `<head>`: contiene información sobre la página.
- `<title>`: define el título de la página.
- `<body>`: contiene el contenido visible.
- `<h1>` a `<h6>`: crean encabezados.
- `<p>`: crea párrafos.
- `<a>`: crea enlaces.
- `<img>`: inserta imágenes.
- `<button>`: crea botones.



## 3. ¿Qué es un atributo de una etiqueta HTML y menciona los más comunes?

Un atributo proporciona información adicional a una etiqueta HTML o modifica su comportamiento.

Algunos atributos comunes son:

- `href`: indica la dirección de un enlace.
- `src`: indica la ubicación de una imagen.
- `alt`: proporciona un texto alternativo para una imagen.
- `class`: permite identificar o agrupar elementos para aplicar estilos.
- `id`: identifica un elemento de forma única.
- `target`: indica dónde se abrirá un enlace.



## 4. ¿Qué es CSS y cómo se utiliza para el diseño web?

CSS significa **Cascading Style Sheets** o Hojas de Estilo en Cascada. Se utiliza para darle diseño y apariencia a una página web.

Con CSS podemos cambiar colores, tipos de letra, tamaños, posiciones, fondos y otros aspectos visuales de los elementos HTML.



## 5. ¿Qué es una propiedad en CSS y menciona las propiedades más comunes?

Una propiedad CSS es una característica que podemos modificar para cambiar la apariencia de un elemento.

Algunas propiedades comunes son:

- `color`: cambia el color del texto.
- `background-color`: cambia el color de fondo.
- `font-size`: cambia el tamaño de la letra.
- `font-family`: cambia el tipo de fuente.
- `text-align`: alinea el texto.
- `width`: cambia el ancho de un elemento.
- `height`: cambia la altura de un elemento.



## 6. ¿Qué es un selector en CSS y cuáles tipos existen?

Un selector CSS permite seleccionar los elementos HTML a los que se les aplicarán determinados estilos.

Algunos tipos de selectores son:

- **Selector de etiqueta:** selecciona elementos por su nombre, por ejemplo `p`.
- **Selector de clase:** selecciona elementos mediante una clase, por ejemplo `.contenedor`.
- **Selector de ID:** selecciona un elemento mediante su identificador, por ejemplo `#titulo`.
- **Selector universal:** selecciona todos los elementos utilizando `*`.



## 7. ¿Qué es JavaScript y cómo añade la interactividad a las páginas web?

JavaScript es un lenguaje de programación utilizado para agregar funcionalidad e interactividad a las páginas web.

Por ejemplo, con JavaScript podemos responder cuando un usuario hace clic en un botón, mostrar mensajes, validar formularios y modificar elementos de una página.



## 8. ¿Cuáles son los tipos de datos primitivos en JavaScript?

Los principales tipos de datos primitivos en JavaScript son:

- **String:** representa texto.
- **Number:** representa números.
- **Boolean:** representa valores verdadero o falso.
- **Undefined:** representa una variable que no tiene un valor asignado.
- **Null:** representa la ausencia intencional de un valor.
- **BigInt:** representa números enteros muy grandes.
- **Symbol:** representa valores únicos.



## 9. ¿Cómo funcionan las estructuras de control de flujo como if, else, switch y bucles en JavaScript?

Estas estructuras permiten controlar cómo se ejecuta el código.

- **if:** ejecuta una acción si se cumple una condición.
- **else:** ejecuta una acción cuando la condición anterior no se cumple.
- **switch:** permite evaluar diferentes opciones según el valor de una variable.
- **Bucles:** permiten repetir un conjunto de instrucciones varias veces. Algunos ejemplos son `for`, `while` y `do while`.


## 10. ¿Por qué es importante usar nombres significativos para variables y métodos?

Es importante utilizar nombres significativos porque permiten entender mejor el código.

Por ejemplo, un nombre como `nombreEstudiante` es más fácil de comprender que un nombre como `x`.

Esto facilita la lectura, el mantenimiento y la modificación del programa, especialmente cuando varias personas trabajan en un mismo proyecto.


## 11. ¿Qué es una variable de entorno y por qué son importantes para JavaScript o la programación en general?

Una variable de entorno es un valor que se almacena fuera del código del programa y que puede ser utilizado por una aplicación.

Son importantes porque permiten guardar configuraciones, como direcciones de servidores, claves o diferentes valores necesarios para ejecutar una aplicación, sin escribirlos directamente dentro del código.



## 12. ¿Qué son las herramientas de desarrollo de Chrome y cómo se accede a ellas?

Las herramientas de desarrollo de Chrome son un conjunto de herramientas que permiten inspeccionar, probar y depurar páginas web.

Se puede acceder a ellas presionando:

**F12**

También se pueden abrir haciendo clic derecho sobre una página y seleccionando **Inspeccionar**.



## 13. ¿Qué se puede hacer en el panel "Elements" de las herramientas de desarrollo?

En el panel **Elements** se puede:

- Ver la estructura HTML de una página.
- Inspeccionar los elementos.
- Revisar y modificar temporalmente el código HTML.
- Observar y modificar los estilos CSS.
- Identificar las clases y atributos de los elementos.



## 14. ¿Cómo se utiliza el panel "Console" y para qué es útil?

El panel **Console** permite visualizar mensajes, errores y resultados generados por JavaScript.

También se pueden escribir y ejecutar instrucciones directamente.

Por ejemplo:

`console.log("Hola Mundo");`

La consola es útil para comprobar si el código funciona correctamente y para identificar errores.



## 15. ¿Qué información se puede obtener del panel "Network" y por qué es importante?

El panel **Network** permite observar las solicitudes que realiza una página web al cargar recursos.

Podemos obtener información sobre:

- Archivos HTML.
- Archivos CSS.
- Archivos JavaScript.
- Imágenes.
- Solicitudes realizadas a servidores.
- Tiempo de carga de los recursos.
- Posibles errores en las solicitudes.

Es importante porque ayuda a analizar el funcionamiento y el rendimiento de una página web, además de facilitar la identificación de problemas relacionados con la carga de recursos.


# Conclusión

HTML permite crear la estructura de una página web, CSS permite darle estilos y JavaScript permite agregar interactividad. Las herramientas de desarrollo del navegador ayudan a inspeccionar y probar el funcionamiento de las aplicaciones web.
